# Style: cinematic-dense

Maximum visual density and cinematic impact. Multiple elements
can compete by design. Higher energy, faster pacing.

## Character

- Rich, layered, film-quality feel
- Multiple visual elements working in concert
- Tighter spacing, faster entrances
- Cinematic patterns used liberally
- High-energy choreography with spring overshoot

## Palette Tendency

Leans toward deep backgrounds, high-contrast accents, moody
lighting. But follows the palette preset chosen in `ontology.yml`.

## Phase Structure

Same `<Series>` phase isolation as editorial-clean. Phases can
be shorter and more rapid-fire. More visual density within
each phase.

## When to Use

- High-energy explainers with rapid cuts
- Cinematic trailers or teasers
- Scenes where multiple visual elements compete by design
- Short-form content (<60s) where density matches pace

## Activation

Set in `ontology.yml`:
```yaml
project:
  style: cinematic-dense
```
